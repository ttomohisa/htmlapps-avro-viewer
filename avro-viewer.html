使い方と注意事項
基本操作
  1. .avroファイルを選択またはドロップします。
  2. ファイル情報でレコード数、ブロック、圧縮方式、メタデータを確認します。
  3. スキーマはTree / Rawで確認します。Treeの項目や「すべて展開 / すべて折りたたむ」で表示を整理でき、開閉状態はファイルごとに保持します。再帰型は参照先を表示します。データはTable / Recordで確認します。
  4. 現在ページをCSVとしてコピーまたは保存できます。
プライバシー
読み込んだファイルはブラウザー内だけで処理します。このアプリから外部サーバーへ送信しません。
注意事項
  • 現在のバージョンはAvro Object Container Fileを対象にします。Raw Avro binaryやRPCデータは対象外です。
  • null / deflate / snappyを内蔵で読み込みます。zstandardはブラウザーがDecompressionStreamで対応している場合に利用します。
  • 閲覧専用です。元のAvroファイルを書き換えません。
  • CSV出力は現在ページの表示列・並び順が対象です。decimal列は精度を保って数値順に並べ、nullは常に末尾に置きます。文字列とdecimalが混在するunionは従来の並び順を使います。表のバイト値は省略表示しますが、CSV・Record詳細・セルの内容とコピーでは末尾まで16進数で表示します。
配布用HTMLは実行時の外部通信を必要とせず、ローカルファイルとして直接開けます。
